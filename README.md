## Getting Started
Crônicas de D&D é um simulador de batalha modo RPG com regras tiradas do livro do jogador de Dungeons & Dragons, um RPG de mesa onde as batalhas acontecem tradicionalmente em um tabuleiro físico ou de forma imaginária, o jogo busca recriar a experiência de uma batalha nesse sistema e trazer um modo extra chamado “Batalha livre”, onde a regra tradicional de turnos é ignorada.
